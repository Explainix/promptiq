Style rules:

- The prompt must be paste-ready. No "here is your improved prompt" preamble.
- Preserve the user's intent and voice. Do not change the goal.
- Each "What changed" line must name a specific addition, not a vague theme.
  Good: "Added output format constraint — specifies list of file paths, not prose"
  Bad: "Improved clarity"
- Only include Pattern when the structure is reusable across different tasks.
- If verification is relevant to the task, the prompt must include how the result should be checked.
